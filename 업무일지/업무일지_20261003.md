## 4. 결정 사항
- 정적 JSON + 클라이언트 집계 (서버/DB 불필요). 투수별 파일은 컬럼형 배열 + gzip, 브라우저 `DecompressionStream` 으로 해제
- 투수 소속팀 = `inning_topbot` 기준 수비팀. 이적 투수는 모든 팀에 등록, 구단 검색으로 들어오면 해당 팀 필터 자동 적용
- 존 높이 : 타자별 `sz_top/sz_bot` 으로 1.5–3.5ft 정규화, `plate_x` 는 포수 시점 그대로
- 색 : 단일 파랑 순차 램프 + 투명도(낮은 구위 옅게, 높은 구위 진하게), 결과는 마커 모양(●/■/▲)으로 구분. 구종 색은 투수 구사율 순 고정 슬롯(팔레트 검증 통과)
- 헛스윙 정의는 파이프라인과 동일하게 `swinging_strike(_blocked)` (foul_tip 제외)
- 2024 점수의 주 패스트볼 기준은 2024 시즌 데이터로 계산 (피처 정의 동일)
