## 4. 결정 사항과 이유
- 시즌 성적 = MLB 공식 기록 (사용자 선택) : ERA·승패·세이브는 Statcast 로 계산 불가
- 중요도 = 승부 영향(WPA) + 구위 하이라이트 (사용자 선택). 경기 중요도 = Σ|타석 WPA| × 유형 가중치(시범 0.5 / 정규 1 / 포스트 1.5 / WS 2.0)
- 근거 하위 페이지 = 개요/구종별/점수대별/투구 1개 (사용자 선택)
- 정규시즌 점수를 바꾸지 않기 위해 피처는 정규·비정규 행을 따로 만들고, 비정규 행의 패스트볼 기준만 정규시즌 값으로 교체
- 경기 IP·피안타·실점은 Statcast 이벤트로 추정 (페이지에 명시). 공식 경기 기록은 사용하지 않음

## 5. 이슈 / 미해결

- OneDrive 의 `web/node_modules` 일부가 클라우드 전용 파일이라 읽기 실패("cloud operation was unsuccessful") → lint·build 는 scratch 로컬 복사본에서 실행. OneDrive 폴더에서 다시 `npm ci` 하거나 node_modules 를 '항상 이 장치에 유지' 로 설정 필요
- 데이터 144MB : Vercel 배포 용량 확인 필요. 줄이려면 타석 설명 문장(`des`) 제외 또는 시범경기만 던진 투수 제외 검토
- 정확한 SHAP 캐시는 2026 정규시즌이 10/36 청크에서 중단된 상태라 현재 export 는 전 시즌 Saabas. 시범·포스트시즌용 extra 캐시는 미계산
- 배포는 하지 않음
