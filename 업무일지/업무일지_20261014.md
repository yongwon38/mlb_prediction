## 2. 생성/수정한 파일
- `hof_net_r.py` (신규) : HOF-Net-R 모델 모듈
  - `HOFNetR` : 피처 토큰 → Transformer 2층(d=32, 4헤드) → MLP. 마지막 은닉층 16차원 = 잔차 basis z(x), f(x) = 결정적 평균 (P1)
  - `fit_mean` : 표준화 타깃 MSE, KL 없음, 홀드아웃 RMSE 조기 종료, epoch 별 telemetry(train/holdout R², Var(ŷ), grad norm)
  - `VarHead` / `fit_var_head` : 평균 고정 뒤 σ_a²(x) 만 NLL 학습 (two-stage)
  - `BLRHead` : 닫힌형식 Bayesian linear residual head (논문 식 21–24, Cholesky, 1/σ_a²(x) 가중)
  - `VIHead` / `fit_vi_head` : q(ω) = N(m, diag s²), 배치평균 NLL + KL/N (식 20)
  - `ZIBHead` / `fit_zib_head` / `zib_predict(_net)` : 영과잉 Beta 헤드 (식 25–29), m_B logit 에 공유 ω (KL/N)
  - `global_kl_per_observation`, `zero_inflated_beta_nll` : 논문 부록 B Listing 1·2 그대로
  - 지표 : `gauss_metrics`, `zib_metrics` (CRPS, 커버리지·보정 오차, 0점 Brier, 공통 bin log score)
- `hofnet_r_experiment.py` (신규) : 실행 스크립트 `python hofnet_r_experiment.py --part synth|real [--smoke] [--threads N]`
  - real : 1 데이터 → 2 P0 기준선(상수·Ridge·LGBM v4 운영 + 시드 재학습 4개 + 이분산 오차모델), 기존 HOF-Net(`outputs/hofnet_nopt/hof_{A0,A0-β0.01,A5}.pt`) → 3 HOF-Net-R P1·P2·P2h·P3·P4 (시드 5개) → 4 투수 cluster bootstrap(RMSE) → 5 구위 지표(`hofnet_experiment.py` 4절 함수를 exec 로 그대로 사용) + ρ whiff bootstrap → 6 불확실성(표본 크기 곡선, OOD 구속) → 7 Go/No-Go (`summary.json`)

## 4. 결정 사항과 이유
- P1 의 basis z(x) 는 평균 헤드의 마지막 은닉층 (Bayesian last layer). MSE 로 끝까지 학습하면 잔차와 z 가 거의 직교라 BLR 사후 평균은 작고, ω 는 주로 불확실성(U_global) 표현용
- ZIB 는 고정 encoder 위 헤드로 학습 (논문 4.1 "Proper distribution third" 순서). 정확한 1 이 없어(최대 0.818) ZOIB 불필요
- ZIB vs Gaussian 은 NLL 을 직접 비교하지 않고 CRPS·공통 bin log score·0점 Brier 로 비교 (논문 4.8절)
- 기존 HOF-Net 은 재학습 없이 `outputs/hofnet_nopt/` 시드 42 모델 사용 (`.pt` 의 변수 순서가 v4 와 같음을 assert 로 확인, HAVAA 는 v3·v4 동일 assert)
- 합성 E1 학습 예산 : 작은 N 에서 batch 1024 는 epoch 당 step 이 2개뿐이라 batch 256(N ≤ 2000) / 1024(그 외), 최대 100 epoch, patience 6. 계산량 때문에 **N = 50,000 은 strong · 시드 42 만** (첫 실행에서 N=10,000 한 시드가 700초 → 전체 10시간 이상 예상되어 축소)
- LGBM 은 기존 관례대로 학습 + 홀드아웃으로 학습(신경망은 학습셋만, 홀드아웃은 조기 종료) — 신경망에 약간 불리한 조건, 보고서에 명시
