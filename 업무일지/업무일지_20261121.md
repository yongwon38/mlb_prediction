# 업무일지 2026-11-21 — 웹 UI 개편 : 토스 감성 · 전문가 분석 사이트 톤 (브랜치 `ui-toss`)

## 1. 작업 요약
- 배경 : 모니터링 등 AI 기능 개선에 앞서 전체 UI 정비. 요청 = 토스(Toss)처럼 미니멀하고 전문적인 느낌, 기본 이모지·기호처럼 "AI가 만든 티"가 나는 요소를 없애고 실제 이미지를 써서 전문가가 운영하는 분석 사이트처럼
- 사용자 결정 : main 에서 새 브랜치 / 이미지 = MLB 공식 선수 사진 + 팀 로고 + 자체 SVG 아이콘 / 범위 = 토스 감성 + 데이터 밀도 유지 (토스 로고·폰트·Tossface 등 자산은 쓰지 않고 색·여백·타이포 감성만)
- 진단 : 컬러 이모지는 없었고, 텍스트 기호(`→ ↗ ← ▲▼ ↑↓ ›`)가 링크·정렬·노트·접이식 아이콘으로 쓰여 생성형 UI 느낌. 사람·팀 이미지가 하나도 없어 숫자와 회색 카드뿐. 웜 그레이 톤과 대문자 eyebrow 라벨도 템플릿 느낌
- 데이터·계산 로직, URL 상태, i18n 키 구조는 바꾸지 않음

## 4. 결정 사항과 이유
- 이미지는 외부 CDN 직접 링크 (`<img loading="lazy">`) : static export 라 next/image 최적화 불가, 저장소·배포 용량 증가 없음
- 차트 결과 기호(●■▲◆★, `ResultMarker`)와 구위 diverging 램프·카테고리 팔레트는 데이터 인코딩이므로 유지
- 선수 사진·팀 로고는 MLB 저작물 → 하단에 출처와 "비공식 분석 사이트" 명시
- good/bad 색은 의미(투수 관점 좋음/나쁨) 그대로, 톤만 조정

## 5. 이슈 / 미해결
- `git switch main` 이 샌드박스에서 `.git/HEAD` 쓰기 거부로 중간에 멈춤 (작업 트리만 main 으로 바뀜) → `git symbolic-ref HEAD refs/heads/main` 로 마무리. git 쓰기는 샌드박스 밖에서 실행할 것
- Claude in Chrome 이 로컬 미리보기 서버에 접속하지 못해 자동 캡처 검증은 못 함 (사용자 직접 확인으로 대체)
- `feature/monitoring` 의 `/model` 페이지는 이 브랜치에 없음 → 모니터링 병합 때 새 토큰·아이콘에 맞춰 정리 필요 (내비 항목 포함)
