## 4. 결정 사항과 이유
- 데이터 = HF 데이터셋 parquet (사용자 선택) : 무료·카드 등록 없음·용량 여유. DuckDB/pandas 로 SQL 조회 가능
- 모델 = git 커밋 (사용자 선택) : push 한 번으로 모델·코드·웹이 함께 반영. 현재 웹 모델 `models/v2` 만 추적
- 일일 배치 = 현재 시즌만 증분 (사용자 선택). 지난 시즌은 HF 스냅샷 `web_data/{web_id}/` 재사용
- `web_id` = 3·4단계 모델 + export 코드 해시 → 바뀌면 스냅샷이 없어져 **전 시즌 자동 재생성** (diff 판정 로직 불필요)
- 진행 중 시즌은 SHAP 대신 Saabas : 피처(투수별 주 패스트볼 평균)가 새 투구가 들어올 때마다 바뀌어 캐시가 매일 무효화됨. 끝난 시즌(12월 이후)만 SHAP
- 최근 3일 재수집 + 경기(game_pk) 단위 교체 : Savant 정정·지연 반영
- GitHub 의 60일 비활성 cron 정지 방지 : `data_status.json` 을 데이터 변경일 + 주 1회 커밋
