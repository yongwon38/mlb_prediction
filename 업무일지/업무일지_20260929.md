## 3. 주요 결과
- 데이터 : `games_25_final.pkl` 정규시즌 712,528구 / 학습 ~2025-08-28 (588,716) / 검증 2025-08-29~09-28 (123,812)
- **1단계 (RandomForest, max_depth=16, min_samples_leaf=25)** — 검증셋
  | 모델 | logloss | accuracy |
  |---|---|---|
  | Prior | 0.9164 | 0.6764 |
  | DecisionTree | 0.5316 | 0.7901 |
  | RandomForest | **0.4490** | **0.8165** |
  - 학습셋 OOF logloss 0.4581 (3단계 y 에는 OOF 예측 사용)
- **2단계** : Gamma(a=0.657, scale=0.728) → Beta(a=0.423, b=2.228). 실제 결과별 평균 타구질 score : 아웃 0.079 / 1루타 0.240 / 2·3루타 0.415 / 홈런 0.677 → 순서 정상
- **3단계 (LGBM, 랜덤서치 12회, 내부 홀드아웃 = 학습셋 마지막 2주)** — 검증셋
  | 모델 | RMSE | MAE | R² |
  |---|---|---|---|
  | 평균 baseline | 0.16750 | 0.12235 | 0.000 |
  | LGBM | **0.16093** | **0.11223** | **0.077** |
  - 예측 10분위별 실제 타구질이 단조 증가 (0.013 → 0.164) → 순위 설명력 확인
  - best params : num_leaves=127, min_child_samples=400, lr=0.02, colsample=0.8, subsample=0.7, lambda=5
- **4단계** : 학습기간 중앙값 50.00, 왜도 0.000, 범위 20~80 / 검증기간 중앙값 50.16
  - 검증기간 투수×구종(100구+) : Spearman corr(구위, whiff%) = **0.713**, corr(구위, xwOBAcon) = −0.271
  - 투수 단위(300구+) corr(구위, whiff%) = 0.591. 상위 : Misiorowski, Greene, deGrom, E. Pérez, Skenes 등 상식적
  - 구종별 평균 : FS/CH/SL 높음, SI/FF 낮음, EP 27.6

## 4. 결정 사항 (해석·가정)
- `games_25.pkl` 은 06-30 까지만 있어 전체 시즌이 있는 `games_25_final.pkl` 사용
- 파울플라이아웃은 `type == 'X'`(hit_into_play)로 기록되므로 인플레이 필터로 포함됨. `field_error` 는 아웃(0) 처리
- 2단계 Beta 모수는 E/3 적률법 추정, `score = BetaPPF(GammaCDF(E))`
- 3단계 : 로케이션 제외(tjStuff+ 방식, 사용자 확인). 좌투 수평성분 부호 반전, 주 패스트볼 대비 차이 변수 추가. foul_tip 은 파울로 보고 제외
- 4단계 스케일러는 학습기간 **전체 투구**의 예측값 분포로 적합 (구위는 결과와 무관하게 모든 투구에 정의)

## 5. 이슈 / 미해결
- 3단계 R² 0.077 로 낮음 — 타구 결과 노이즈가 큰 문제라 예상 범위지만 개선 여지 있음
- 투구 단위 score 를 투수 평균하면 분포가 50 근처로 압축됨 (상위 투수 ~55). 투수/구종 단위 재스케일 여부 검토 필요
