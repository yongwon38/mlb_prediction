## 4. 결정 사항과 이유
- Waste 존 기준 = Savant 어택존 Waste (사용자 선택). 높이는 타자별 존으로 정규화한 값 기준
- VAA·HAA 는 원값 사용 (사용자 선택). 높이 보정 버전은 미적용
- 스케일러는 점수 대상(waste 제외) 학습기간 투구로 적합 → 점수가 매겨지는 투구 기준 중앙값 50
- 공정 비교를 위해 v1 도 같은 waste 제외 + 같은 대상 집합으로 스케일러 재적합(`v1r`)해서 비교
- **v2 채택 근거** : 타당성(whiff%·xwOBAcon 상관), 연도 간 안정성, 다음 시즌 whiff% 예측력, OOS Whiff 격차 모두 v2 우세. BA 격차(−0.004)·MAE(+0.0004)만 근소 열세
