## 1. 작업 요약
- 새 페이지 `/explain` : 투수별 구위 점수가 나온 이유를 **전체 / 구종별 / 점수대별 / 개별 투구** 단위로 표시
  - 투구마다 `기준 점수 S0 + 요인 8개 기여 = 구위`가 정확히 성립하도록 모델 기여를 점수 단위로 변환 (`k_i = (s_i − S0)/(pred_i − base)` 비례 배분)
  - 요인 그룹 : 구속 / 수직 무브먼트 / 수평 무브먼트 / 진입각·궤적 / 릴리스 위치 / 익스텐션 / 회전 / 구종·투구손 (얽힌 변수를 묶어 해석 안정화)
  - 구성 : 요인별 기여 막대 + 리그 동일 구종 구성 기준선, 자동 근거 문장(원값 vs 리그 동일 구종 평균), 구종×요인·점수대×요인 행렬(행 클릭 = 필터), 투구 목록(구위 높은/낮은/날짜순) + 워터폴 + 원값 표
- 분석 페이지 연결 : 투수 헤더 "구위 산출 근거 →", 투구 분포도 점 클릭(마우스) → 해당 투구 상세로 이동·자동 스크롤

- 기준 점수 S0 = 50.03. 리그 평균 그룹 기여 ≈ 0 (최대 |0.65|). 구종별 : EP 는 구속 −3.3·익스텐션 −4.9 등 전부 −, FS/CH/SL 은 진입각·구종 +, SI 는 진입각 −3.3
- Skenes 2026 : 평균 52.0 = 50.0 + 2.0 (릴리스 위치 +1.3 = 낮은 팔각도 26°, 구속 +0.8, 진입각 −0.4). 워터폴 합 = 투구 구위 일치 확인
- 설명 파일 시즌당 약 15MB. 배포 https://stuff-lab.vercel.app (`stuff-lon7lq5j0`)

## 4. 이슈 / 발견
- **진입각·궤적(VAA·HAA) 그룹이 기여 크기의 대부분** (평균 |기여| 0.039 vs 다른 그룹 0.001~0.010, 예측 단위). Skenes 점수대별 : 60+ 구간 진입각 +9.3, <40 구간 −10.6 → 같은 투수 안에서 좋은 공/나쁜 공을 가르는 것은 사실상 진입각 = 투구 위치 정보
