### 7-8. HOF-Net vs LGBM(v3) 비교 (`hof_net.py`, `hofnet_experiment.py`, `hofnet_followup.py`, `stuff_pipeline_261010_hofnet.ipynb`)
- 보고서 : Claude Docs 「HOF-Net vs LGBM 비교」 https://claude.ai/code/artifact/b92a7aed-2d06-40b0-8d38-b811a6b1ee39
- HOF-Net(초안 부록 A) PyTorch 구현 : 피처 토큰 + Transformer 2층, 투구별 사후분포 N(μ(x), DR(x)D), 덧셈형 예측기 b + Σ W_k h_k, 이분산 Gaussian, 조건부 사전분포 τ(x), EM 교대 ELBO
- 변수·표본·split·지표는 v3 와 동일 (LGBM v3 지표가 5차 H5★ 와 완전 일치 = 재현 확인)
- 초안 그대로(A0, β = 1)와 대각(A1)은 posterior collapse : 홀드아웃 RMSE = 상수 예측(0.1705). 신호가 약해(R² 약 2%) 투구별 KL 비용 > 우도 이득. MSE 로는 같은 구조가 평균을 학습 → 버그 아님
- 보완판 추가 : KL β 0.1·0.01, β-NLL(Seitzer 2022, 0.5). 최선 HOF = A5(결정적) 계열이지만 모두 LGBM 미만 (투수×구종 ρ whiff 0.719 vs A5 0.675, A0-βNLL 0.611)
- U_latent 는 전체 불확실성의 1% 미만, OOD(구속 >98) AUROC 0.5~0.66 → 불확실성 장점 미미. LGBM + 이분산 오차 모델이 NLL·CRPS 동급
- 구위 산출 근거 : HOFNetStuffModel 을 운영 explain_contrib 에 그대로 넣어 가능 확인 (가법성 오차 0.003~0.12점). 확률판은 근거의 57% 가 구종·투구손에 몰림
- 권고 : 운영 LGBM v3 유지. 운영 반영 없음
- 진행 이슈 : 첫 실행에서 붕괴 발견 → β·β-NLL 판 추가해 재실행 (총 약 30분). LGBM 이분산 기준선 보정 계수 오류(×1.27 → ×e^1.27) 수정 후 후속 스크립트로 재계산
