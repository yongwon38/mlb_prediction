## 4. 결정 사항과 이유
- 반올림 해시는 해시 방식이 바뀌어 한 번 전체 재계산이 필요했음 (공개 레포라 Actions 무료)
- VAA 높이 보정만으로는 위치 누수가 안 줄어듦 : 위치는 `vz0`·`vx0` 등 궤적 초기값으로 거의 그대로 재구성됨 (C도 R² 0.967)
- D가 '공 자체의 위력'에 가장 가까움 (위치 의존성↓, 안정성·다음 시즌 예측력↑). 투구 단위 적합도와 구간 격차는 낮아짐 → 위치 덕분의 맞힘이 빠진 것
- 웹 i18n : URL 구조는 그대로, 언어는 `?lang=` → 저장된 선택 → 브라우저 언어 순. `export_web_data.py`는 수정하지 않음 (데이터 속 한국어 라벨은 프런트에서 코드·순서로 번역 → `web_id` 불변, 재생성 없음)
