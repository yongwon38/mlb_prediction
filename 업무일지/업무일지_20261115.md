## 4. 결정 사항과 해석
- "정확도 향상" 가설은 기각 : 운영 조건(배럴 아웃 포함)에서 1단계 logloss 0.449 → 0.489
- 하지만 구위 점수 관점에서는 **트레이드오프** : 헛스윙 설명력을 조금 잃고(−0.019, CI 0 미포함) 배럴 억제 설명력을 얻음(−0.039, CI 0 미포함). 하드힛%(95mph+)는 차이 없음 → "강한 타구 전반"이 아니라 "배럴" 쪽으로 기울어짐
- 주의 : 배럴%·xwOBAcon 개선 일부는 B 의 타깃이 배럴 여부에 더 가까워졌기 때문 (평가 지표 쪽으로 기운 효과, 8절 H7 과 비슷한 성격)
- 원래 구조에서도 3단계 타깃은 1단계 OOF 예측(타구 물리값 기반)이라 '담장 앞에서 잡힌 배럴' 의 운은 이미 빠져 있다. B 가 바꾸는 것은 확률 보정(배럴 가중치)뿐
- 같은 효과를 원하면 데이터를 빼는 것보다 2단계에서 결과별 가중(E = P1 + 2P2 + 3P3 대신 득점가치 등)을 바꾸는 쪽이 보정을 깨지 않고 의도를 명시적으로 드러낸다
