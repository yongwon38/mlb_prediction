## 1. 작업 요약
- 사용자 질문 : 1단계 타구결과 분류기를 학습할 때 "배럴인데 아웃"된 타구를 빼면(운영 점수에는 포함) 정확도가 오르고, 하드힛 억제를 더 잘 반영하는 구위 점수가 되지 않을까?

## 3. 주요 결과
- 학습기간 배럴 8,874개 중 아웃 2,861개(32%) 제외 → 1단계 학습 103,339 → 100,478행
- A 재현 : 캐시 y3 와 상관 0.99993, |차이| 평균 0.0013 (sklearn 1.7.1 → 1.9.0 차이), 검증 ρ(whiff) 0.7165 = 웹 v4 0.717

- → 정확도가 오른 것처럼 보이는 건 배럴 아웃을 뺀 평가셋에서만. 실제 타구 전체로는 나빠짐 (B 는 배럴 P(아웃)을 체계적으로 과소 추정)

## 4. 결정 사항과 해석
- "정확도 향상" 가설은 기각 : 운영 조건(배럴 아웃 포함)에서 1단계 logloss 0.449 → 0.489
- 하지만 구위 점수 관점에서는 **트레이드오프** : 헛스윙 설명력을 조금 잃고(−0.019, CI 0 미포함) 배럴 억제 설명력을 얻음(−0.039, CI 0 미포함). 하드힛%(95mph+)는 차이 없음 → "강한 타구 전반"이 아니라 "배럴" 쪽으로 기울어짐
- 주의 : 배럴%·xwOBAcon 개선 일부는 B 의 타깃이 배럴 여부에 더 가까워졌기 때문 (평가 지표 쪽으로 기운 효과, 8절 H7 과 비슷한 성격)
- 원래 구조에서도 3단계 타깃은 1단계 OOF 예측(타구 물리값 기반)이라 '담장 앞에서 잡힌 배럴' 의 운은 이미 빠져 있다. B 가 바꾸는 것은 확률 보정(배럴 가중치)뿐
- 같은 효과를 원하면 데이터를 빼는 것보다 2단계에서 결과별 가중(E = P1 + 2P2 + 3P3 대신 득점가치 등)을 바꾸는 쪽이 보정을 깨지 않고 의도를 명시적으로 드러낸다

## 7. 추가 실험 : 같은 효과가 HOF-Net-R 에서도 나는가 (시드 42, 반영 없음)
- 사용자 질문 : LGBM 에서 본 트레이드오프가 HOF-Net-R(웹 대체 모델)에서도 같은가. 실험만, 운영 반영 없음
- 구현
  - `barrel_out_experiment.py` : A·B 의 y3 를 `outputs/barrel_out/y3_ab.parquet` 로 저장하는 한 줄 추가 (git 제외, 다른 결과는 부동소수점 끝자리만 달라 커밋본 유지)
  - `barrel_out_hof_experiment.py` (신규, `--smoke`) : `hofnet_diag_experiment.py` 기준선과 같은 호출(`hr.fit_mean` 30 epoch 조기 종료 → P1, `hr.fit_zib_head` → P4 M=4)로 A·B 를 학습. ZIB 헤드도 각 변형의 y3 로 학습. 지표·bootstrap 은 LGBM 실험 5절과 같음. GPU 61초
  - 출력 `outputs/barrel_out/hof/` : `results.csv`, `compare.csv`(LGBM vs HOF B − A), `epochs.csv`, `log.txt`
- 재현 : HOF A P4 ρ(whiff) 0.7041 = 진단 실험 기준선 0.704

### 결과 (검증 투수×구종 341개, B − A [95% CI], 시드 잡음 σ≈0.016)
| 지표 | LGBM v4 | HOF P1 | HOF P4 (웹 구조) |
|---|---|---|---|
| ρ(구위, whiff%) ↑ | −0.019 [−0.034, −0.005] | −0.023 [−0.045, −0.005] | +0.003 [−0.013, +0.018] |
| ρ(구위, xwOBAcon) ↓ | −0.021 [−0.039, −0.004] | −0.002 [−0.019, +0.017] | −0.013 [−0.031, +0.004] |
| ρ(구위, 배럴%) ↓ | −0.039 [−0.056, −0.023] | −0.014 [−0.034, +0.003] | −0.019 [−0.035, −0.004] |
| ρ(구위, 하드힛%) ↓ | −0.009 | −0.001 | −0.010 |
| 예측력 2026 whiff% / 배럴% | −0.013 / −0.029 | −0.030 / −0.016 | −0.000 / −0.014 |

- HOF A → B 원값 : P4 ρ(whiff) 0.704 → 0.707, ρ(배럴%) −0.230 → −0.249 / P1 ρ(whiff) 0.681 → 0.658
- 해석
  - 방향은 같다 : 세 모델 모두 배럴% 설명력이 좋아지는 쪽 (B 의 타깃이 배럴에 더 가까워졌으므로 예상된 방향)
  - 크기는 HOF 에서 더 작고 시드 잡음 수준 : 배럴% 개선 0.014~0.019 (LGBM 0.039), 대부분 σ 0.016 안팎
  - 헛스윙 손실은 HOF P1 에서만 보이고(−0.023) P4(웹 구조)에서는 없음(+0.003). 다만 P4 는 ZIB 헤드가 실행 간 차이를 줄여 보이는 경향이 있어(10/17 진단과 같음) "손실 없음" 으로 단정하기 어렵다
  - 결론 : "HOF 에서도 같은 효과" 라고 보기엔 근거가 약하다. 같은 방향이지만 단일 시드로는 잡음과 구분되지 않는 크기. LGBM 에서도 이득(배럴%)과 손실(whiff)이 맞바뀌는 수준이라 반영 이유 없음
