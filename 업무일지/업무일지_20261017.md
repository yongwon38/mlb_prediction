## 4. 결정 사항과 이유
- 평가 헤드는 P1·P4 둘 다 : P4 는 실험 간 차이를 줄여 보여서 원인 판별은 P1 이 더 선명
- 판단 기준 : 시드 잡음(5시드 P4 표준편차 0.016)보다 큰 차이 + bootstrap CI. bootstrap 은 평가 표본 불확실성만 반영하므로 시드 잡음 기준을 우선

## 7. 추가 실험 : cosine + SWA 15 epoch (h2b_cos_swa15)
- 사용자 방침 : 시드는 42 로만 실험한다 (5시드 확인은 하지 않음)
- 동기 : h2_cos_swa(30 epoch, 마지막 10 epoch 평균)는 epoch 7 이후 과적합 구간까지 평균해 홀드아웃 RMSE 0.16913, 예측력 0.707 로 나빠졌다 → 학습을 15 epoch 로 줄이고 마지막 5 epoch(11~15)를 평균
- 구현 : `run_hof(..., epochs=)` 인자 추가, `--runs h2b`. GPU 약 40초
- 결과 (LGBM 0.717)

| 실험 | P1 ρ | P4 ρ | P4 RMSE | P4 예측력 |
|---|---|---|---|---|
| 기준선 | 0.681 | 0.704 | 0.16825 | 0.752 |
| cosine+SWA 30 epoch | 0.684 | 0.714 | 0.16874 | 0.738 |
| cosine+SWA 15 epoch | 0.679 | 0.702 | 0.16837 | 0.743 |

- 해석 : 과적합을 줄이니 RMSE 는 기준선 수준으로 돌아왔지만 ρ 개선(+0.010)도 사라졌다. 30 epoch 판의 개선은 시드 잡음 범위의 운이었을 가능성이 크다 → 학습 스케줄 조정은 개선책에서 뺀다

## 8. 추가 실험 : 헛스윙 다중 과제 (h7_mt_l05, h7_mt_l10)
- 설계 : 학습기간 비-waste 스윙 263,605구(기존 tr_rows + 학습에 안 쓰던 파울 112,554구)의 헛스윙 여부를 보조 과제(BCE, 기저 z 위 Linear)로 추가. 손실 = y3 마스크 MSE + λ·BCE, 조기 종료는 홀드아웃 y3 RMSE. `fit_mean_mt`, `--runs h7`. GPU 1.3분
- 결과 (LGBM : ρ whiff 0.717, ρ xwOBAcon −0.244)

| 실험 | ρ whiff P1 / P4 | ρ xwOBAcon P1 / P4 | RMSE P1 / P4 |
|---|---|---|---|
| 기준선 | 0.681 / 0.704 | −0.264 / −0.222 | 0.16835 / 0.16825 |
| λ = 0.5 | 0.667 / 0.707 | −0.243 / −0.225 | 0.16835 / 0.16836 |
| λ = 1.0 | 0.709 / 0.701 | −0.223 / −0.184 | 0.16837 / 0.16860 |

- 해석 : P4(웹 구조)는 변화 없음. λ=1.0 P1 의 +0.028 은 λ=0.5 에서 반대로 나타나 일관성이 없고, xwOBAcon 타당도가 약해져 평가 지표(whiff) 쪽으로 기운 것에 가깝다. 보조 헤드 홀드아웃 whiff AUC 0.65 로 학습은 됨 → 다중 과제는 개선책 아님
- 보고서에 H7 절, 부록 표 2행, 개선 방향 갱신

## 9. 질의응답·결정 사항
- **이전에 못 한 작업** : 원인 실험 전에 제안한 'ρ(whiff) 기준 조기 종료'는 하지 않았다. epoch별 ρ 기록으로 보면 30 epoch 중 최고 epoch 의 P1 ρ 가 0.709(h2_noes epoch 25)로 상한이어도 LGBM 0.717 미만이다. 이 값은 검증 데이터에서 최댓값을 고른 것이라 부풀려져 있고, 공정하게 하려면 별도 투수 집합이 필요하다 → 기대 이득 +0.01 안팎으로 보고 진행하지 않음
- **논문 P5 (attention 공분산 diagonal / full / random 비교)** : 미실시(10/16 업무일지와 같음). 공분산은 잔차 가중치 ω 사후분포의 퍼짐만 바꾸는데, U_global 이 예측 분산의 0.01% 라 점수 순위에는 거의 영향이 없다. 또 HOF-Net-R 의 ω 는 피처 단위가 아니라 16차원 잠재 공간이라, attention(피처×피처)을 붙이려면 d_r 을 피처 수로 바꿔 Stage I 부터 재학습해야 한다 → 성능 목적이면 건너뛰고, 논문 검증 목적일 때만 진행. 예상 결론은 'C 가 B·D 를 이기지 못함'(기여 철회)
- **cosine + SWA 설명** : cosine = 학습률을 코사인 곡선으로 0 근처까지 줄임, SWA = 마지막 여러 epoch 가중치 평균(학습 한 번 안의 앙상블, 예측 비용 그대로)
- 시드 42 고정 방침은 Claude 메모리에도 저장했다
